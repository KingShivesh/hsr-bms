# Deferred Features

These features are NOT part of the pilot. They will not be built until
one club is live and paying, and stable for two weeks.

## Not Building Before Pilot

- Public branded booking page
- QR code per table (public-facing)
- Multi-location support
- Split payments
- Refund flow
- GST invoicing
- Tournament management
- Loyalty and rewards
- Inventory management
- Staff shift and payroll
- Smart lighting integration
- AI insights
- Native mobile apps
- Multi-currency
- Customer-facing receipts via email
- Advanced analytics and BI
- Custom reports
- Data export tools
- Webhook integrations
- API for third parties

## Defining Sentence

This app exists to let one club start tables, add canteen items,
close bills, track member credit, and see what happened -- without
calling me.

## Rule

Every time I am tempted to build something from this list,
I read this file and remember: none of it matters until club #1
is live and paying.
